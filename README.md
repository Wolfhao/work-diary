# Work Diary 工作日记

> 个人工作台微信小程序

一个面向个人（博主/自由职业者）的**多功能工作台小程序**，将日常工作所需的实用工具聚合在一个小程序中，持续迭代扩展。

## 模块规划

| 模块 | 状态 | 实现方式 | 说明 |
|------|------|----------|------|
| 商单管理 | ✅ 已上线 | 前后端全栈 | 商单全生命周期管理、垫付/收入双账务追踪、数据看板统计 |
| 旅游攻略 | ✅ 已上线 | 纯小程序端 | 静态攻略内容展示，无需后端接口 |
| 记账本 | 🚧 规划中 | 前后端全栈 | 聊天式 AI 记账、资产管理、账单报表 |

## 已上线功能

### 商单管理

| 功能 | 说明 |
|------|------|
| 微信一键登录 | `wx.login()` code 换取 Token，自动注册 |
| 商单全生命周期 | 待开工 → 制作中 → 待结款 → 已完成，支持截图附件 |
| 双账务追踪 | 分别追踪垫付（是否已收回）与收入（是否已到账） |
| 数据看板 | 总垫付、待收回、总收入、已到账、净利润等关键指标 |
| 多维筛选 | 按状态、平台（小红书/抖音/B站等）筛选搜索 |
| 文件上传 | 支持本地 / COS / MinIO 灵活切换 |

### 旅游攻略

纯小程序端实现，静态内容展示，包含完整行程规划（景点/餐饮/交通/住宿）。
